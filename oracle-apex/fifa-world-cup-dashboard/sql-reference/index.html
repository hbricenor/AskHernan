SQL Reference

FIFA World Cup Analytics Dashboard

This section contains SQL queries used in the Oracle APEX FIFA World Cup Analytics Dashboard. These queries support dashboards, interactive reports, and business analytics functionality.

Core Tables

  • TEAM
  • MATCHES
  • STADIUM

Key SQL Queries

1. Match Schedule Query

Retrieves match schedule including teams, stadium, date, and round information. 

SELECT 
    MATCH_ID,
    MATCH_DATE,
    HOME_TEAM_ID,
    AWAY_TEAM_ID,
    STADIUM_ID,
    HOME_GOALS,
    AWAY_GOALS,
    ROUND_NAME
FROM MATCHES
ORDER BY MATCH_DATE, MATCH_ID;

2. Total Goals per Match

Calculates total goals scored in each match. 

SELECT 
    MATCH_ID,
    (HOME_GOALS + AWAY_GOALS) AS TOTAL_GOALS
FROM MATCHES;

3. Goals by Team (Home + Away)

Aggregates total goals scored by each team. 

SELECT 
    TEAM_ID,
    SUM(HOME_GOALS + AWAY_GOALS) AS TOTAL_GOALS
FROM MATCHES
GROUP BY TEAM_ID;

4. Matches per Stadium

Counts number of matches played in each stadium. 

SELECT 
    STADIUM_ID,
    COUNT(*) AS TOTAL_MATCHES
FROM MATCHES
GROUP BY STADIUM_ID;
