FIFA World Cup Analytics Dashboard

This section documents PL/SQL business logic used in the FIFA World Cup Analytics Dashboard built with Oracle APEX. The package encapsulates calculations, KPIs, and reusable database logic for tournament analytics.

PL/SQL Package

PKG_FIFA_STATS

Core PL/SQL package responsible for generating FIFA analytics, including match statistics, goal calculations, and KPI summaries.

Package Overview

  • Encapsulates business logic for FIFA analytics
  • Centralizes KPI calculations
  • Supports Oracle APEX dashboards and reports
  • Improves code reusability and maintainability

Key Procedures (Conceptual)

1. Calculate Total Goals

FUNCTION get_total_goals RETURN NUMBER
IS
    v_total NUMBER;
BEGIN
    SELECT SUM(HOME_GOALS + AWAY_GOALS)
    INTO v_total
    FROM MATCHES;

    RETURN v_total;
END;

2. Matches by Team

FUNCTION get_matches_by_team(p_team_id NUMBER) RETURN NUMBER
IS
    v_count NUMBER;
BEGIN
    SELECT COUNT(*)
    INTO v_count
    FROM MATCHES
    WHERE HOME_TEAM_ID = p_team_id
       OR AWAY_TEAM_ID = p_team_id;

    RETURN v_count;
END;

3. Goals by Match

FUNCTION get_match_goals(p_match_id NUMBER) RETURN NUMBER
IS
    v_goals NUMBER;
BEGIN
    SELECT (HOME_GOALS + AWAY_GOALS)
    INTO v_goals
    FROM MATCHES
    WHERE MATCH_ID = p_match_id;

    RETURN v_goals;
END;
