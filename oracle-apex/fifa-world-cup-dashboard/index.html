FIFA World Cup Analytics Dashboard

Oracle APEX Analytics & Business Intelligence Demonstration

This Oracle APEX application was developed as a portfolio project to demonstrate enterprise application development using Oracle Database, Oracle SQL, PL/SQL, interactive reports, dashboards, charts, and business intelligence techniques.

The project simulates a FIFA World Cup tournament management system, allowing users to explore match statistics, stadium information, participating teams, tournament rounds, and executive dashboards.

Business Objectives

  • Develop an enterprise Oracle APEX application.
  • Create executive dashboards using Oracle Charts.
  • Build interactive reports for business users.
  • Demonstrate Oracle SQL reporting techniques.
  • Apply PL/SQL programming and business logic.
  • Present data using modern Business Intelligence principles.

Application Features

  • Executive Dashboard
  • Interactive Reports
  • Team Management
  • Stadium Management
  • Match Schedule
  • Matches by Round
  • Matches by Stadium
  • Home vs Away Goals Analysis
