FIFA World Cup Analytics Dashboard

Project Documentation

This document provides a high-level overview of the FIFA World Cup Analytics Dashboard built using Oracle APEX, Oracle SQL, and PL/SQL. It demonstrates end-to-end enterprise application design, data modeling, and business intelligence concepts.

1. Project Overview

  • Oracle APEX-based analytics application
  • FIFA World Cup simulation dashboard
  • Interactive reporting and KPI visualization
  • Built on Oracle Database with SQL and PL/SQL

2. Business Objective

  • Track tournament performance and match results
  • Analyze team and stadium statistics
  • Provide executive-level dashboards
  • Support data-driven decision making

3. Functional Scope

  • View teams, matches, and stadiums
  • Display match schedules and results
  • Interactive dashboards with KPIs
  • Filters by round and stadium

4. Data Model

  • TEAM table: stores team information
  • MATCHES table: stores match results and scores
  • STADIUM table: stores venue information
  • Relationships: MATCHES links teams and stadiums

5. Process Flow

  • Data stored in Oracle tables
  • SQL queries retrieve and aggregate data
  • PL/SQL package calculates KPIs
  • Oracle APEX displays dashboards and reports
  • Users interact with reports and filters

6. Key KPIs

  • Total Goals Scored
  • Matches Played
  • Average Goals per Match
  • Team Performance Metrics
  • Stadium Utilization

7. Technical Architecture

  • Oracle APEX (User Interface Layer)
  • Oracle SQL (Data Query Layer)
  • PL/SQL (Business Logic Layer)
  • Oracle Database (Data Storage Layer)

8. Screenshots

  • Home Dashboard
  • Executive Dashboard

9. Lessons Learned

  • Dashboard design requires business understanding, not only SQL skills
  • PL/SQL improves maintainability and centralizes logic
  • Oracle APEX accelerates enterprise application development
  • Data modeling is critical for analytics accuracy

10. Future Enhancements

  • User authentication and role-based access
  • Integration with Oracle Cloud Infrastructure
  • Advanced analytics and forecasting
  • Power BI integration for external reporting
  • REST API integration
