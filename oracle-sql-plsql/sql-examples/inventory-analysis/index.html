Inventory Analysis Query

Supply Chain Analytics Example

Business Scenario

A Supply Chain team requires visibility into inventory levels across warehouses to identify low-stock items, support replenishment planning, and improve inventory management.

Objective

Provide current inventory balances by product and vendor, including quantities on hand and quantities committed to customer orders.

Sample SQL

SELECT
    VEND_ITEM.VEND_ITEM_ID,
    VEND_ITEM.VENDOR_NUM,
    VENDOR.VEND_NAME,
    VEND_ITEM.ITEM_NUM,
    SUM(ITEM_W.ON_HAND) AS ON_HAND,
    SUM(INV_SHP_L.TO_ALLOC_QTY) AS ON_SALE_QTY
FROM ...
GROUP BY ...
ORDER BY VEND_ITEM.VENDOR_NUM,
         VEND_ITEM.ITEM_NUM;

Note: Table names, identifiers, and business-specific details have been sanitized for portfolio purposes.

Business Value

  • Improves inventory visibility
  • Supports replenishment decisions
  • Reduces stockout risk
  • Supports purchasing and planning activities
  • Provides actionable supply chain insights
